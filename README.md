# PPC  Tracking Application

Sub-contractor material tracking application (polishing and plating vendor workflows) for Titan. This repository contains both the frontend and backend.

## Structure

```
Titan-PPC/
  frontend/   # Next.js (App Router), TypeScript, Tailwind
  backend/    # FastAPI (async), SQLAlchemy, Alembic
```

## Prerequisites

- Node.js 20+
- Python 3.11+
- PostgreSQL
